# 五福荟 R1.1 交互原型

本目录为版本评审原型，参考既有 H5 和运营平台做增量设计。详细基线、用户故事、截图与测试结果见 [设计说明](../docs/design/wufuhui_r1.1/README.md)。

## 本地运行

需要 Node.js 22.13+。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:3111/ 。外发入口演示为 http://127.0.0.1:3111/?entry=daily 。`npm run build` 生成静态构建结果。

顶部切换运营配置、H5 用户原型与设计说明。运营端保存草稿和发布分离，发布后 H5 读取同一环境的配置。H5 场景面板可切换新/老用户、生成失败、权益不足及页面；手机上先展开“演示设置”。

数据仅保存在当前浏览器；不输入真实手机号或出生资料。报告与卡牌均为示例，不调用短信、账户、排盘、模型、支付等服务。生产环境选项也只是隔离的本地演示配置。

`src/reference` 的样式来自 M-satoriSrs 指定 H5 基线，保留原有设计语言；`src/style.css` 仅作独立评审容器适配与版本新增组件补充。正式前后台未被修改。
