# R1.1 商业领域枚举与状态机

本文冻结 R1.1 商业模块共享语言。代码、数据库、OpenAPI、前端和测试必须使用相同枚举语义。

## 1. 通用枚举

| 类型 | 值 |
| --- | --- |
| BusinessSpace | `C_CONSUMER`、`B_ACADEMY_ASSISTANT` |
| ServiceType | `DAILY_ENERGY`、`CARD_READING` |
| UsageUnit | `COUNT`、`REPORT`、`MINUTE`、`IMAGE` |
| BenefitSourceType | `PURCHASE`、`MEMBERSHIP`、`PROMOTION`、`COMPENSATION`、`MIGRATION` |
| SelectionMode | `SYSTEM_RULE` |
| ExpiryTimezone | R1.1 固定 `Asia/Shanghai` |

## 2. 商品与报价

| 对象 | 状态/类型 |
| --- | --- |
| OfferingStatus | `DRAFT`、`ACTIVE`、`INACTIVE`、`RETIRED` |
| OfferingKind | `SINGLE_SERVICE`、`SERVICE_PACK`、`MEMBERSHIP_PLAN` |
| OfferingAudience | `ALL`、`NEW_USER_ONLY` |
| QuoteStatus | `ACTIVE`、`USED`、`EXPIRED`、`REVOKED` |
| PromotionStatus | `DRAFT`、`ACTIVE`、`INACTIVE`、`EXPIRED` |

商品版本发布后不可修改；变更价格、权益、有效期、限购、协议或退款规则必须创建新版本。

## 3. 订单、支付、交付与退款

| 对象 | 状态 |
| --- | --- |
| MoneyOrderStatus | `AWAITING_PAYMENT`、`PAID`、`FULFILLING`、`FULFILLED`、`FULFILLMENT_FAILED`、`CLOSED`、`REFUNDING`、`REFUNDED`、`PARTIALLY_REFUNDED` |
| PaymentAttemptStatus | `CREATED`、`PENDING`、`SUCCEEDED`、`FAILED`、`CLOSED` |
| FulfillmentStatus | `PENDING`、`RUNNING`、`RETRY_WAITING`、`SUCCEEDED`、`FAILED_FINAL`、`REVERSING`、`REVERSED` |
| RefundStatus | `QUOTED`、`REQUESTED`、`PROCESSING`、`SUCCEEDED`、`FAILED`、`CANCELLED` |
| PaymentProviderCode | R1.1 `WECHAT_PAY`；测试 `FAKE` |

```text
AWAITING_PAYMENT → PAID → FULFILLING → FULFILLED
AWAITING_PAYMENT → CLOSED
FULFILLING → FULFILLMENT_FAILED → REFUNDING → REFUNDED
FULFILLED → REFUNDING → REFUNDED / PARTIALLY_REFUNDED
```

订单、支付尝试、交付和退款状态必须独立保存，不能由一个状态推断并覆盖另一个事实。

## 4. 服务权益账本

| 对象 | 状态/动作 |
| --- | --- |
| EntitlementGrantStatus | `PENDING`、`AVAILABLE`、`RESERVED`、`FROZEN`、`EXHAUSTED`、`EXPIRED`、`FORFEITED`、`REVERSED` |
| EntitlementEntryType | `GRANT`、`RESERVE`、`COMMIT`、`RELEASE`、`REVERSE`、`EXPIRE`、`FREEZE`、`UNFREEZE`、`FORFEIT`、`ADJUSTMENT` |

同一 reservation 只能进入一个结算终态：`COMMIT` 或 `RELEASE`。退款、平台补偿和人工调整使用反向或调整记录，不修改历史流水。

## 5. 智慧种子账本

| 对象 | 状态/动作 |
| --- | --- |
| SeedGrantStatus | `AVAILABLE`、`RESERVED`、`EXHAUSTED`、`EXPIRED`、`REVERSED` |
| SeedEntryType | `GRANT`、`RESERVE`、`CONSUME`、`RELEASE`、`RESTORE`、`EXPIRE`、`ADJUSTMENT` |
| SeedPurpose | `SERVICE_EXPERIENCE`、`ACTIVITY_PRICE_UNLOCK` |

智慧种子不是人民币支付方式，不能出现充值、提现、转账、人民币抵扣或固定汇率状态。

## 6. 核销决策与消费意图

| 对象 | 状态 |
| --- | --- |
| ResolutionStatus | `RESOLVED`、`NO_SOURCE`、`RESERVED`、`EXPIRED`、`SUPERSEDED` |
| ConsumptionIntentStatus | `RESERVED`、`RUNNING`、`COMMITTED`、`RELEASED`、`EXPIRED`、`FAILED` |
| ConsumptionAction | `RESERVE`、`START`、`COMMIT`、`RELEASE`、`EXPIRE`、`RECONCILE` |

```text
RESERVED --正式抽卡--> RUNNING --完整交付--> COMMITTED
RESERVED --30分钟未抽卡--> EXPIRED
RESERVED/RUNNING --取消或失败--> RELEASED
```

核销选择固定为 `SYSTEM_RULE`，不存在用户选择或偏好枚举。

## 7. 会员与升级

| 对象 | 状态 |
| --- | --- |
| MembershipPlanCode | `GLOW`、`SERENITY`、`FREEDOM` |
| SubscriptionStatus | `SCHEDULED`、`ACTIVE`、`EXPIRED`、`TERMINATED_BY_UPGRADE`、`CANCELLED` |
| UpgradeStatus | `QUOTED`、`AWAITING_PAYMENT`、`FULFILLING`、`COMPLETED`、`FAILED` |
| OldEntitlementDisposition | `FORFEITED` |

允许升级：`GLOW→SERENITY`、`GLOW→FREEDOM`、`SERENITY→FREEDOM`。不支持即时降级。

升级剩余价值测算不是资金状态，不产生 refund、抵扣、应付或用户退款展示。
