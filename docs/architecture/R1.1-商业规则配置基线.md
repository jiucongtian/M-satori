# R1.1 商业规则配置基线

## 时间规则

| 配置 | 冻结值 |
| --- | --- |
| `checkoutQuoteTtlMinutes` | 15 |
| `unpaidOrderTtlMinutes` | 30 |
| `preDrawReservationTtlMinutes` | 30 |
| `expiryTimezone` | `Asia/Shanghai` |
| `membershipPeriodDays` | 30 |

权益包自然日有效期算法：支付成功所在的 `Asia/Shanghai` 日期计为第 1 天，在第 N 个自然日 `23:59:59.999` 到期；数据库保存对应 UTC、原始时区和规则版本。

## 固定核销规则

规则版本：`consumption-priority-r1.1-v1`。

1. 适用且有效的当前会员周期权益；
2. 最早到期的人民币专项权益包；
3. 最早到期的适用智慧种子批次；
4. 无来源时返回购买建议。

同一来源类别按 `expiresAt ASC, grantedAt ASC, id ASC` 排序。用户不能覆盖系统选择。

## 问事计量

- 人民币购买权益或会员权益：每份完整问事报告核销 `1 READING_CREDIT`，不按卡数增加。
- 智慧种子：按 1—5 张卡的版本化规则计算；具体数量由运营配置发布。
- 预留时冻结成本与规则版本，后续调价不改变已有消费意图。

## 活动价种子生命周期

```text
报价：只校验资格
订单创建：预留种子
支付成功：消耗种子
订单取消/30分钟超时/支付失败：释放种子
```

普通退款是否恢复活动种子由订单快照中的规则决定；会员升级旧周期剩余权益与此无关。

## 会员规则

- 仅月度 30 天方案；不开自动续费、季度、年度。
- 有效会员手动续费时创建未来周期，不提前发放权益。
- 到期后购买立即开始。
- 周期权益不结转。
- 升级新方案全额支付并立即替换；旧权益 `FORFEITED`，剩余价值只作内部测算。

## 普通退款策略模型

`RefundPolicyVersion` 至少包含：适用商品、未开始规则、已使用规则、可退比例算法、权益冻结规则、活动种子恢复规则、平台无法履约规则、未成年人/监管例外和生效时间。

普通退款策略必须随订单快照保存。会员升级旧周期剩余价值禁止引用 `RefundPolicyVersion`，禁止创建退款对象。
