# R1.1 商品、支付与权益核销清单

## 统一规则

- 智慧种子直接消费仅用于每日指引：1 颗核销 1 次。
- 智慧种子的另一用途是解锁会员计划或服务包活动价：报价时判断，创建订单时预留，微信支付成功后核销；取消、超时或支付失败自动释放。
- 智慧种子不折算人民币、不直接支付抽卡问事。
- 服务核销顺序：当前会员权益 → 最早到期的已购权益包；每日指引在两者均不可用时再使用智慧种子。
- 新注册用户赠送 3 颗智慧种子。

## 支付方式

- 用户真实支付：微信 JSAPI 支付。
- 测试环境可使用 `FAKE` 支付提供方和 ¥0.01 微信联调商品；不得出现在正式用户目录。
- 当前不是“种子 + 现金”的组合支付。种子负责解锁并在支付成功后核销，人民币负责支付活动价。

## 功能核销

| 功能 | 可用来源 | 单次核销量 | 无权益处理 |
| --- | --- | ---: | --- |
| 每日指引 | 会员 → 已购服务包/单次 → 智慧种子 | 权益 1 次或种子 1 颗 | 常规弹窗引导“我的权益”，不展示内部错误和请求号 |
| 抽卡问事 | 会员 → 已购服务包/单次 | 1 次问事权益，与抽牌张数无关 | 引导购买问事单品、服务包或会员 |

## 活动价展示与账务时点

1. SHOP-02 商品详情展示活动价、门槛、当前资格。
2. ORDER-01 再次展示原价、应付活动价、支付成功后核销颗数，并由用户点击支付确认。
3. 创建订单后预留种子，避免并发重复使用。
4. 微信支付成功后才正式消费种子并发放权益。
5. 订单关闭、过期或支付失败时释放原预留种子。
