# R1.1 商业能力追踪矩阵

| Capability | 核心接口 | 事实表 | 核心事件 | 验证重点 |
| --- | --- | --- | --- | --- |
| commerce-catalog-pricing | `/service-offerings*`、`/membership-plans`、`/checkout-quotes` | service_offerings、offering_versions、seed_promotion_rules、checkout_quotes | OfferingVersionPublished、CheckoutQuoteIssued | 版本不可变、15分钟报价、限购、活动价不形成汇率 |
| money-order-payment-fulfillment | `/money-orders*`、`/payment-attempts*`、微信回调、`/refund-quotes`、`/refunds` | money_orders、order_snapshots、payment_attempts、payment_events、fulfillment_jobs、refunds | MoneyOrderCreated、PaymentSucceeded、FulfillmentRequested/Succeeded/Failed、RefundSucceeded | 重复回调、支付/交付分离、30分钟关单、普通退款和异常退回 |
| service-entitlement-ledger | `/me/entitlements*`、`/me/usage-records` | entitlement_grants、entitlement_usage_entries | EntitlementGranted/Reserved/Committed/Released | 多包独立到期、行锁、只追加、来源分离、负余额防护 |
| complimentary-seed-ledger | 兼容 `/me/wisdom-seed-*` | complimentary_seed_grants、allocations、entries、projection | SeedGranted/Reserved/Consumed/Released | 批次范围、最早到期、多批分配、旧余额迁移、活动价生命周期 |
| entitlement-resolution-consumption | `/entitlement-resolutions`、`/consumption-intents*` | entitlement_resolutions、resolution_candidates、consumption_intents、reservation_allocations | ConsumptionReserved/Started/Committed/Released | 固定优先级、禁止用户选择、30分钟释放、崩溃重放 |
| membership-lifecycle-upgrade | `/memberships/current`、`/memberships/periods`、`/membership-upgrades/preview`、`/membership-upgrades` | membership_subscriptions、membership_periods、membership_upgrades、upgrade_assessments | MembershipPeriodScheduled/Started/Ended、MembershipUpgradeCompleted | 单一有效周期、续费排队、不结转、全额新订单、内部剩余价值仅测算 |

## 跨能力场景

| 场景 | 关联能力 | 自动化级别 |
| --- | --- | --- |
| 已有会员权益完成一次问事 | resolution + entitlement + membership | integration/E2E |
| 会员无额度、专项包可用 | resolution + entitlement | integration |
| 仅智慧种子可用且按卡数消耗 | resolution + seed | integration/E2E |
| 无权益、报价、下单、支付、发权益、恢复原业务 | catalog + order/payment/fulfillment + entitlement | E2E |
| 支付回调重复/乱序 | payment + order + fulfillment | integration/E2E |
| 交付最终失败自动异常退回 | fulfillment + payment/refund | E2E |
| 同类权益包重叠并按最早到期核销 | entitlement + resolution | integration |
| 预留后未抽卡 30 分钟释放 | consumption + selected ledger | worker/integration |
| 生成超过 30 分钟后成功核销 | consumption + generation + selected ledger | E2E |
| 有效会员续费形成未来周期 | membership + fulfillment + entitlement | integration |
| 会员升级新方案成功、旧权益作废且无退款 | membership + order/payment + entitlement | E2E |
| 种子旧余额迁移前后对账一致 | seed + migration + reconciliation | migration/integration |

## 自动化证据定位

- 商品、报价、订单、支付、交付、普通退款：`backend/tests/integration/order-payment-flow.test.ts`
- 服务权益、行锁、独立到期、只追加流水：`backend/tests/integration/entitlement-ledger.test.ts`
- 种子批次、跨批分配、迁移投影：`backend/tests/integration/complimentary-seed-ledger.test.ts`
- 固定优先级、预留、超时与恢复：`backend/tests/integration/consumption-orchestration.test.ts`
- 会员周期、续费、升级和失败保留旧方案：`backend/tests/integration/membership-flow.test.ts`
- H5 路由、服务端定价、固定来源和 opaque 上下文恢复：`frontend/tests/commerce-flow.test.mjs`
- PostgreSQL 迁移、约束与 RBAC：`backend/tests/integration/commerce-schema.test.ts`、`backend/tests/integration/operator-rbac.test.ts`
- 压测与 SLO：`backend/scripts/benchmark-r11-commerce.ts`
