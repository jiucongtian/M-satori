# R1.1 商业领域事件目录

## 事件 envelope

所有事件必须包含：`eventId`、`eventType`、`eventVersion`、`occurredAt`、`producer`、`aggregateType`、`aggregateId`、`businessSpace`、`requestId`、`correlationId`、`causationId`、`idempotencyKey` 和最小必要 `payload`。

事件与业务状态在同一 PostgreSQL 事务写入 Outbox。消费者使用 Inbox 或业务唯一键去重，按至少一次投递处理。

## 隐私限制

事件 payload 只允许稳定 ID、状态、金额、币种、数量、版本和错误码。禁止包含问事原文、报告正文、第三方姓名、支付证书、完整回调原文或用户敏感档案。
