# 五福荟 R1.2 需求备忘

记录日期：2026-09-10。来源：用户本轮需求说明。状态：后续版本备忘，尚未细化为可开发 PRD，不计入 `wufuhui_r1.1` 验收。

## WFH12-01：五福关系匹配

以自己为中心，将关系按五福映射呈现：

| 五福 | 用户明确的关系方向 | 说明 |
| --- | --- | --- |
| 福 | 父母 | 可录入本人父母、岳父岳母、公公婆婆等多位对象 |
| 禄 | 亲子 | 录入子女关系对象 |
| 喜 | 亲密 | 录入亲密关系对象 |
| 财 | 客户 | 客户关系；用户同时提及合作伙伴，其分类归属及报告差异待明确 |
| 寿 | 自我状态 | 指向本人状态，不凭空增加第五种他人关系 |

四种外部关系均支持录入关系对象的生命智慧信息，用自己的四张卡与选定对象的四张卡进行关系分析，生成报告。每类可包含多位对象；是否批量生成、是否支持一个人属于多个关系、报告如何组合，待 R1.2 细化。

关系页面是生命智慧档案的关系映射视图：这里录入的信息最终也能在生命智慧档案中看到，底层应复用同一档案，不维护互不相通的副本。需进一步定义已有档案选择、重复对象合并、关系标签、修改同步、删除关系与删除档案的区别，以及对象资料使用授权。

这项关系匹配重构不等同于 R1.1 的报告表达升级。

## WFH12-02：卡牌皮肤选择与运营配置

用户可在生命智慧卡牌/智慧牌库/智慧档案相关体验中，为自己的生命智慧卡牌选择不同皮肤。运营后台管理可供选择的卡牌视觉资源。

待 R1.2 设计：皮肤预览与切换入口、选择作用于单卡/一套四卡/全局的范围、不同卡牌的展示方式、后台上架/下架、默认与回退、历史报告如何呈现、可用资格及是否收费。

“皮肤”暂按视觉表现理解，不默认修改干支或计算事实；如果用户期望切换的是另一套知识卡牌体系，需要单独明确。当前需求不是让用户选择或修改自己的出生排盘结果。

## WFH12-03：真太阳时

用户已提出“真太阳时”作为 R1.2 交付方向，目前未给出详细规则。

正式 PRD 需明确出生地经纬度、时区与历史夏令时、时间修正算法和数据来源、原始时间与修正时间展示、是否可选、未知时间处理、跨日/时辰边界、既有档案重算及历史报告影响。算法版本和标准样例需要专门确认，当前备忘不指定公式或默认开关行为。
