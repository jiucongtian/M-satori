# 品牌与小岁说报告规范

需求：WFH11-01、WFH11-02、WFH11-07。

## 1. 五福荟品牌

用户明确要求将现有“初见”品牌和 Logo 改为“五福荟”。替换范围覆盖本版实际交付的登录注册、建档、首页、导航、报告、分享预览及新生成海报，以及运营后台和 POC 中的产品品牌展示。浏览器标题、站点图标和图片替代文本一并核对。

正式 Logo、比例、深浅背景用法及最小显示尺寸待提供。设计验收必须覆盖小屏、加载失败、分享图片和后台展示，不能仅检查首页。图片失败时仍应显示“五福荟”文字，不出现破图遮挡主操作。

历史文档、代码标识、接口路径、域名和历史交易主体不因品牌更换而机械重命名。历史报告内容及已交付分享产物不静默改写；是否补生成五福荟版历史分享图另行确认。协议、支付等涉及主体身份的名称使用真实主体，不能由品牌替换误改。

## 2. 小岁说一期

### 已确认要求

- 小岁是用于报告讲述的 IP，创作背景是太岁；面向用户使用轻量的“小岁”形象。
- 每份报告正文之前显示小岁画像，以及非常简短、不超过 30 字的小岁介绍。
- 正文持续使用小岁解读报告与用户关系的视角，不能只有开头加一句“小岁说”、后面仍是无角色的静态结论。
- 第二阶段增加语音；R1.1 不出现无法使用的播放入口。

### 待确认的叙述口径

用户同时提到“第三人称视角”和“小岁给你讲报告”。当前草案按“小岁是讲述角色、用户称为你”组织，最终冻结需确认小岁自称“我”还是“小岁”。示例仅说明语气，不代表正式介绍：

> 小岁陪你读懂五福，照顾当下的自己。

正文示例：“小岁想提醒你，今天可以先听听自己的感受，再决定怎样开口。”不得把用户改成疏离的“命主”或“他/她”作为默认叙事。

介绍字数按用户可见字符计，标点计入，换行不计；最多 30 个。该计数口径是设计建议，评审时冻结。介绍、头像及讲述口吻统一版本，报告标题和适用日期仍清晰可见。

## 3. 五福内容组织

每个人都有五福。任何本版交付报告都应尽量从五福及其关系组织解读，具体映射、章节和知识依据以逐份提供的模板为准。

不能把 R1.2 的“福—父母、禄—亲子、喜—亲密、财—客户、寿—自我状态”直接当作所有 R1.1 报告的已冻结算法，也不能在没有关系对象输入时编造对象及碰撞结论。报告只有本人或当日卡牌输入时，必须使用与该输入相符的模板。

调整分两层处理：内容模板决定五福结构与叙述；计算规则决定卡牌事实和关系结果。需要改变计算规则时，必须明确输入、映射、规则版本及标准案例，以对应 CR 记录，不能由模型自由补全。每日能量的既定分数、等级等事实不能仅因换叙述口吻而改变。

### 模板交接清单

每份模板至少记录：报告类型、适用场景、输入条件、五福映射、必选/可选章节、叙述人称、字数范围、示例、知识依据、版本、确认人和验收样例。一个模板通过不代表其他类型同时通过。

| 报告范围 | R1.1 处理 | 目前依赖 |
| --- | --- | --- |
| 建档后的基础报告/四卡初识 | 按实际交付形态纳入品牌、小岁及五福模板 | 正式模板与样例待提供 |
| 每日指引详情 | 首次体验和首页后续访问使用同一内容规则 | 正式模板与样例待提供 |
| 抽卡问事报告 | 对本版开放的单卡/双卡/多卡分别覆盖 | 各模式模板或兼容规则待提供 |
| 当前版实际开放的其他报告 | 评审列出清单，逐项对应模板；不自动新增报告产品 | 完整报告清单待冻结 |
| POC 报告 | 与正式目标共享已确认的表达和结构要求 | POC 入口、样例及模板待提供 |

### 结构草案

小岁画像与短介绍 → 对本次问题/日期/用户情境的开场 → 按该报告模板展开五福及关系 → 具体可尝试的行动 → 小岁收尾。

以上是评审骨架，不是对每种报告强制统一的固定五章。模板缺少某一维度依据时，不虚构内容凑结构；是否隐藏、说明或使用其他表达，由该模板明确。

## 4. 一致性与历史

报告详情、摘要和分享内容应来自同一份报告结果。新报告保存模板和规则版本，验收可以回溯具体模板；已经交付的历史报告保留当时内容。过渡期间旧报告可处于新品牌页面中，但不能将旧正文标成已按新模板生成。

模板不合法、缺少必填章节或事实与输入不一致时，不向用户交付假成功报告；保留任务状态并按既有生成失败恢复机制处理。重试不能重复扣减智慧种子或权益。

## 5. POC 同步

POC 必须同时调整讲述者视角和内容结构，并与相同报告类型的正式目标做并排核对。静态样稿可以用于评审但须标明样稿，不能作为真实生成已联通的证据。

本需求尚未提供 POC 的具体页面/仓库/部署入口，不能默认等同于任一同名本地目录。进入实现前确认范围及至少一份现有样例、对应的新模板；验收覆盖开头、五福正文、建议、收尾及小屏阅读。
