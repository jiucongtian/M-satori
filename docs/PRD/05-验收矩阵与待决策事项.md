## 3. 发布条件

- 本版需求均有唯一类型标签、版本标签、负责人及可执行验收条件，PR/commit 回链到对应 Issue。
- 阻塞对应交付的素材及决策完成，正式环境使用已确认素材与模板。
- 运行本版变更的定向测试与直接关联回归；品牌、内容及 POC 有人工样稿/页面确认。
- 发布候选进行既有 Release Gate 要求的验证，报告事实、档案、任务、权益与导航主路径可用。
- 未完成项明确从版本移出并记录产品决定，不能通过静默删验收项达成“全部通过”。

本次只交付 PRD 及需求治理记录，不执行应用功能开发或环境部署。
