# 四卡初识报告本地确定性生成

## 目标

新用户首次建立本人生命智慧档案后，四卡初识报告不调用 RAG、LLM 或 Aqua Workflow，而是使用版本化知识与固定规则直接生成并持久化报告。

## 运行方式

所有环境固定注册 `DeterministicProfileFirstLookGenerator`。该能力没有启用开关、生成器选择器或 Aqua 回退配置，因此测试与生产使用同一段本地代码和同一份版本化知识。

## 知识基线

- 知识版本：`lianshanyi-profile/1.0.0`
- 规则版本：`profile-season-rules/1.0.0`
- 文案版本：`profile-first-look-copy/1.0.0`
- 原始来源：`连山易知识/wiki/知识/06.六十甲子表.md#四柱特质`
- 覆盖范围：60 个甲子 × 时/日/月/年四柱，共 240 条且不允许空缺
- 生成文件记录源表 SHA-256；导入脚本在记录数、甲子唯一性或任一柱位缺失时失败

四卡映射保持不变：`SELF → hour/思想`、`FAMILY → day/行为`、`CAREER → month/事业`、`SPACETIME → year/梦想目标`。

## 五季规则

五季固定为：`春、夏、长夏、秋、冬`。每张卡拆成天干季节和地支季节，共八个等权节点。

地支季节以已发布 60 卡组合为准：`辰=春、未=夏、戌=秋、丑=冬`；不使用地支在传统资料中的多重季节归属重新推导。

整体分类：

1. 唯一第一名且不少于 4 点：`dominant`。
2. 唯一第一名且少于 4 点：`moderate`。
3. 恰有两个并列第一且高于第三名：`dual`。
4. 其他分布：`balanced`，以日卡地支为第一回落、日卡天干为第二回落。

内在判断使用时卡与日卡的四个节点；并列时依次参考全部地支、日卡地支、固定五季顺序。外在判断使用月卡与年卡的四个节点；并列时依次参考全部天干、日卡天干、固定五季顺序。

内外关系按五行比和、相生、相克和其他互补关系生成固定模板，不做自然语言推断。

## 输出与兼容

- 继续返回 `ProfileFirstLookContent schemaVersion=1.0.0`。
- 继续使用 `profile_first_look_reports`、幂等键、`READY/FAILED` 状态和历史版本持久化。
- Manifest 改为 provider-neutral 字符串，并为本地报告增加 `generator`、`ruleVersion`、`knowledgeRelease`。
- 历史 Aqua 报告无需迁移，仍可由 GET 回读。
- 前端不再把四卡初识报告标记为“Aqua 正在生成”或“AI 生成内容”；每日完整指引的 AI 声明保持不变。

## 验证要求

- 知识完整性：60 卡、240 单元、零空值。
- 确定性：相同四卡输入的 `content` 必须完全相同。
- 边界：覆盖单季主导、双季、五季平衡、内外并列与日卡回落。
- 性能：测试环境目标 `POST first-look p95 < 200ms`，以真实数据库链路压测结果为准。
- 回退：通过正常代码版本回滚恢复上一实现；不得删除已持久化的本地或历史 Aqua 报告。
