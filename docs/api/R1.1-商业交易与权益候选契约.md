# R1.1 商业交易与权益候选契约

Base URL：`/api/v1`。所有命令使用 `Idempotency-Key`；错误 envelope 延续 R1.0，并增加 `retryable`、`nextAction` 和必要的 `retryAfterSeconds`。

## 商品与报价

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/service-offerings` | 当前可售商品，支持 `serviceType`、`kind`、cursor、limit |
| GET | `/service-offerings/{offeringId}` | 当前商品详情和发布版本 |
| GET | `/membership-plans` | 三档月度会员方案 |
| POST | `/checkout-quotes` | 创建 15 分钟权威报价 |

`POST /checkout-quotes` 请求只包含 `offeringId`、可选 `offeringVersion` 和 opaque `businessContext`。响应包含 `quoteId`、人民币分、币种、权益快照、有效期和活动价资格。不得返回种子人民币汇率。

## 订单、支付与退款

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/money-orders` | 根据 quote 创建订单 |
| GET | `/money-orders` | 我的订单游标列表 |
| GET | `/money-orders/{orderId}` | 订单、支付和交付摘要 |
| POST | `/money-orders/{orderId}/cancel` | 关闭未支付订单 |
| POST | `/money-orders/{orderId}/payment-attempts` | 创建微信支付尝试 |
| GET | `/payment-attempts/{paymentAttemptId}` | 查询支付事实 |
| POST | `/internal/payment-webhooks/wechat` | 微信支付验签回调，不使用用户鉴权 |
| POST | `/money-orders/{orderId}/refund-quotes` | 普通订单退款测算 |
| POST | `/money-orders/{orderId}/refund-requests` | 普通订单退款申请 |
| GET | `/refunds` | 我的普通退款列表 |
| GET | `/refunds/{refundId}` | 普通退款进度 |

会员升级旧周期剩余价值不能调用退款接口。

## 权益与流水

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/me/entitlements` | 按来源返回权益批次 |
| GET | `/me/entitlements/{entitlementId}` | 权益批次详情 |
| GET | `/me/usage-records` | 预留、核销、恢复、作废和调整记录 |
| GET | `/me/wisdom-seed-account` | 兼容 R1.0 的种子账户投影 |
| GET | `/me/wisdom-seed-transactions` | 兼容 R1.0 的种子流水 |

## 固定核销与消费

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/entitlement-resolutions` | 系统按固定优先级解析并返回结果 |
| POST | `/consumption-intents` | 基于 resolution 创建并预留 |
| GET | `/consumption-intents/{intentId}` | 查询选中来源和状态 |
| POST | `/consumption-intents/{intentId}/start` | 正式抽卡/业务开始，取消 30 分钟短超时 |
| POST | `/consumption-intents/{intentId}/commit` | 仅供内部业务交付调用 |
| POST | `/consumption-intents/{intentId}/release` | 仅供内部业务失败/取消调用 |

不提供用户 selection 或 source override 接口。客户端提交 `sourceId` 返回 `ENTITLEMENT_SOURCE_NOT_CLIENT_SELECTABLE`。

## 会员、续费和升级

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/membership-subscriptions/current` | 当前及未来周期 |
| GET | `/membership-subscriptions/{subscriptionId}` | 周期与权益引用 |
| POST | `/membership-renewal-quotes` | 手动续费报价 |
| POST | `/membership-upgrade-quotes` | 全额新方案报价和替换提示 |
| GET | `/membership-upgrades/{upgradeId}` | 升级交付状态，不返回退款字段 |

升级确认响应必须包含 `oldPlanEndsImmediately=true`、`unusedBenefitsCarryOver=false` 和用户可读提示，不包含 `refundAmount`、`cashOffset` 或退款规则。

## 主要错误码

| 领域 | 错误码 |
| --- | --- |
| 商品/报价 | `OFFERING_NOT_AVAILABLE`、`OFFERING_VERSION_CHANGED`、`PURCHASE_LIMIT_REACHED`、`CHECKOUT_QUOTE_EXPIRED`、`PROMOTION_NOT_ELIGIBLE` |
| 订单/支付 | `ORDER_ALREADY_PAID`、`ORDER_CLOSED`、`PAYMENT_RESULT_PENDING`、`PAYMENT_ALREADY_SUCCEEDED`、`PAYMENT_PROVIDER_UNAVAILABLE` |
| 交付 | `FULFILLMENT_IN_PROGRESS`、`FULFILLMENT_FAILED`、`FULFILLMENT_RETRY_EXHAUSTED` |
| 权益/核销 | `ENTITLEMENT_NOT_AVAILABLE`、`ENTITLEMENT_EXPIRED`、`ENTITLEMENT_SOURCE_NOT_CLIENT_SELECTABLE`、`CONSUMPTION_ALREADY_SETTLED`、`CONSUMPTION_INTENT_EXPIRED` |
| 会员 | `MEMBERSHIP_ALREADY_ACTIVE`、`MEMBERSHIP_UPGRADE_NOT_ALLOWED`、`MEMBERSHIP_UPGRADE_IN_PROGRESS` |
| 普通退款 | `REFUND_NOT_ALLOWED`、`REFUND_ALREADY_EXISTS`、`ENTITLEMENT_FROZEN_FOR_REFUND`、`REFUND_PROCESSING` |

## 分页与时间

- 商品、订单、权益、流水和退款列表使用不透明 cursor；默认 `createdAt DESC, id DESC`。
- 所有瞬时时间使用 RFC 3339 UTC；自然日有效期同时返回 `expiryTimezone=Asia/Shanghai`。
- 响应金额统一为整数分和 `CNY`，数量为整数并带明确 unit。
