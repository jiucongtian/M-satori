# 项目治理文档

本目录保存长期有效的研发规则，不保存一次性的讨论结论。

| 文档 | 用途 | 何时更新 |
| --- | --- | --- |
| `研发与发布SOP.md` | 从需求到提交、测试、部署的最小流程 | 工作方式调整时 |
| `测试与回归规范.md` | 用例编号、定向验证、全量回归与报告 | 新增测试层级或门禁时 |
| `GitHub看板与状态规范.md` | 看板字段、状态和视图 | 项目管理方式调整时 |
| `Release-Gate-模板.md` | 打 Tag 前的准入清单 | 发版规则调整时 |

所有文档由 [PROJECT_PLAYBOOK.md](../../PROJECT_PLAYBOOK.md) 统一索引。
