# R1.0 H5 原型 100% 还原标准

## 基准

- 唯一视觉基准：`M-satoriSrs/h5原型` 当前已确认版本。
- 基准手机视口：390 × 844；同时验证 375 × 812 与 430 × 932 的可用性。
- 页面以 `Release + 页面编号` 建立一一对应关系，不允许用相似页面替代。

## 必须一致

- 页面层级、内容顺序、文案和页面编号。
- 字体层级、字号、字重、行高、颜色和透明度。
- 字体族、字体文件与授权以《R1.0-字体与排版规范》为准；原型视觉不得引入未经批准的具名字体。
- 间距、圆角、边框、阴影、背景和安全区域。
- 图形、卡牌、植物生长视觉和动画节奏。
- 按钮、表单、选中、禁用、加载、空、失败和成功状态。
- 点击区域、跳转目标、返回路径和底部导航状态。

## 验证

1. 原型和研发页面使用相同视口与相同状态数据截图。
2. 自动生成像素差异图和差异比例。
3. 自动差异只能用于定位；最终必须人工确认无可见差异。
4. 视觉一致、交互一致、接口状态一致后，页面才可标记 `accepted`。
