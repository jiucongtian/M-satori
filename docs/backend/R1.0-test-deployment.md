## 发布

服务器端 `.env.production` 不进入 Git。发布时同步代码后执行：

```bash
cd /opt/satori-test/current/backend
docker compose --env-file .env.production -f docker-compose.test.yml up -d --build --wait
```

迁移由一次性 `migrate` 服务先执行；成功后 API 和 Worker 才启动。PostgreSQL/Redis 不暴露公网端口，API 仅绑定 `127.0.0.1:3200`，由 Nginx 提供 HTTPS。

前端使用 `npm run build:static` 导出到 `frontend/out/`，同步至版本化发布目录后切换 `/opt/satori-test/frontend/current` 软链接。Nginx 根路径提供前端静态页面，`/api/v1/` 保持反向代理后端。
