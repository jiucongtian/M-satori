## 性能与发布验证口径

`npm run analyze:static` 报告每个固定路由的 gzip 初始资源总量，以及相对 `/` 新增的业务域 JavaScript。`npm run check:budgets` 将缺失固定路由、首页超过 197.25 KB 或单域新增 JavaScript 超过 100 KB 视为失败。

测试环境发布必须使用不可变目录；切换前核对服务器当前版本，切换后验证固定路由 HTTP 200、gzip/缓存头、API/Worker 健康和核心写操作幂等。上一不可变目录保留为回滚点。

## 2026-08-23 整改验收记录

- 前端发布：`release/r1.0@f1f1995`，测试环境不可变目录 `/opt/satori-test/frontend/releases/f1f1995`。
- 后端保持：`/opt/satori-test/releases/49a8660`；本次没有覆盖后端代码或环境文件。
- 固定路由：`/`、`/login`、`/consent`、`/legal`、`/home`、`/profile/create`、`/daily`、`/daily/report`、`/my`、`/my/profile`、`/my/seeds`、`/my/reports`、`/my/archive` 均直接返回 HTTP 200。
- 性能结果：首页 gzip JS+CSS 为 197.1 KiB，相对 263 KiB 发布基线降低约 25.1%；首页业务域新增 JS 为 0，其他业务域新增 gzip JS 为 70—72 KiB，全部通过 100 KiB 门禁。
- 缓存与压缩：首页 HTML 为 `no-cache` 且启用 gzip；`/_next/static/` 指纹资源为一年 `public, immutable` 且启用 gzip。
- 自动化结果：前端 TypeScript、ESLint、Vinext build、Next 静态导出、OpenAPI lint/生成一致性和 69 项测试通过；后端 lint、typecheck、build、59 项单元测试、23 项契约测试和 5 项集成测试通过。
- 浏览器结果：欢迎页进入 `/login`、协议新标签页、未登录直达 `/home` 安全返回 `/login?next=%2Fhome`、刷新保持路由均通过；修复了业务请求早于 Session 守卫挂载的问题。
- 服务健康：公网 bootstrap 与回环 ready 均为 HTTP 200；API、PostgreSQL、Redis 健康，Worker 运行。
- Nginx 修复：静态导出同时存在 `route.html` 与 `route/` RSC 目录，`try_files` 调整为优先 `$uri.html`，避免子路由补斜杠后 403。
- 回滚演练：新版本首次验证发现子路由 403 后，成功回切上一不可变 release `72fcd35`；修复 Nginx 后再发布并通过全路由验收。当前可回滚点保留 `4483112`、`41fac43` 和 `72fcd35`。

## 明确保留的兼容债务

`/my/profile` 与 `/my/archive` 仍复用旧展示/编辑适配器，以避免本轮同时改写人物档案编辑、删除和初识回看而造成业务回退。该适配器不得被公共首页或认证入口引用；在这两个页面完成独立域内状态机与真实账号 E2E 后删除，最迟不得晚于 R1.0 正式发布候选冻结。旧 `profileSteps` 与 R1.1 原型不得新增 R1.0 路由或导航入口。
