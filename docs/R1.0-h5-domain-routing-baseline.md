## 性能与发布验证口径

`npm run analyze:static` 报告每个固定路由的 gzip 初始资源总量，以及相对 `/` 新增的业务域 JavaScript。`npm run check:budgets` 将缺失固定路由、首页超过 197.25 KB 或单域新增 JavaScript 超过 100 KB 视为失败。

测试环境发布必须使用不可变目录；切换前核对服务器当前版本，切换后验证固定路由 HTTP 200、gzip/缓存头、API/Worker 健康和核心写操作幂等。上一不可变目录保留为回滚点。

## 2026-08-23 整改验收记录

- 前端发布：`release/r1.0@8149a5e`，测试环境不可变目录 `/opt/satori-test/frontend/releases/8149a5e`。
- 后端发布：`release/r1.0@ed167cd`，测试环境不可变目录 `/opt/satori-test/releases/ed167cd`。API 与 Worker 均使用该不可变 release 启动。
- 固定路由：`/`、`/login`、`/consent`、`/legal`、`/home`、`/profile/create`、`/daily`、`/daily/report`、`/my`、`/my/profile`、`/my/seeds`、`/my/reports`、`/my/archive` 均直接返回 HTTP 200。
- 性能结果：首页 gzip JS+CSS 为 197.1 KiB，相对 263 KiB 发布基线降低约 25.1%；首页业务域新增 JS 为 0，其他业务域新增 gzip JS 为 70—72 KiB，全部通过 100 KiB 门禁。受保护页面显式加载兼容业务样式，未依赖访问顺序注入 CSS。
- 缓存与压缩：首页 HTML 为 `no-cache` 且启用 gzip；`/_next/static/` 指纹资源为一年 `public, immutable` 且启用 gzip。
- 自动化结果：前端 TypeScript、ESLint、Vinext build、Next 静态导出、OpenAPI lint/生成一致性和 69 项测试通过；后端 lint、typecheck、build、59 项单元测试、23 项契约测试和 5 项集成测试通过。
- 浏览器结果：使用一次性测试账号完成欢迎页、注册登录、协议页、建档预览/确认、确认态刷新恢复、生命智慧初识、奖励领取、首页、“我的”全部子路由、每日指引生成及报告页的完整 E2E。未登录直达 `/home` 安全返回 `/login?next=%2Fhome`；浏览器前进、后退、刷新和直接访问均保持真实路由。建档和每日生成均执行快速重复点击，后端只形成一个有效结果；每日额度仅从 18 扣至 17。
- 恢复性修复：Session 守卫提升到业务请求挂载之前；HomeOverview 返回最新待确认档案 revision；建档草稿优先保留用户输入名称并在预览前同步持久化，避免刷新或快速提交丢失输入。
- 可访问性与视觉检查：页面标题随路由更新，路由切换后焦点进入页面区域，Tab 可到达返回按钮；390×844 移动视口无横向溢出，核心页面控制台无 error/warn，加载、空态、错误态和返回入口均有可识别文本。
- 服务健康：公网 bootstrap 与回环 ready 均为 HTTP 200；API、Worker、PostgreSQL、Redis 均健康，真实每日指引后台任务成功完成并生成报告。
- Nginx 修复：静态导出同时存在 `route.html` 与 `route/` RSC 目录，`try_files` 调整为优先 `$uri.html`，避免子路由补斜杠后 403。
- 回滚演练：新版本首次验证发现子路由 403 后，成功回切上一不可变 release `72fcd35`；修复 Nginx 后再发布并通过全路由验收。当前前端 release 可回滚到 `6618329`、`3e141fc` 或更早的 `72fcd35`，后端可回滚到上一不可变 release。

## 明确保留的兼容债务

`/my/profile` 与 `/my/archive` 仍复用旧展示/编辑适配器，以避免本轮同时改写人物档案编辑、删除和初识回看而造成业务回退。该适配器不得被公共首页或认证入口引用；在这两个页面完成独立域内状态机与真实账号 E2E 后删除，最迟不得晚于 R1.0 正式发布候选冻结。旧 `profileSteps` 与 R1.1 原型不得新增 R1.0 路由或导航入口。
