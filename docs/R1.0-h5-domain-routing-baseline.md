## API 与写操作护栏

| 场景 | 读取 | 写入（只允许用户显式触发） |
| --- | --- | --- |
| Session | `bootstrap`、`refresh`、`me` | `sendSms`、`createSession`、`acceptConsents`、`logout` |
| 建档 | `homeOverview`、`profileRevision`、`profileFirstLook` | `previewProfile`、`confirmProfile`、`generateProfileFirstLook`、`claimRegistrationReward` |
| 每日指引 | `dailyInsight`、`generationTask`、`seedAccount` | `createTodayInsight` |
| 我的 | `profiles`、`seedTransactions` | 人物档案 create/preview/confirm/update/delete |

所有写入继续通过现有 API Client 的 `Idempotency-Key`，路由挂载、刷新和只读页面不得调用写接口。

## 性能与发布验证口径

`npm run analyze:static` 报告每个固定路由的 gzip 初始资源总量，以及相对 `/` 新增的业务域 JavaScript。`npm run check:budgets` 将缺失固定路由、首页超过 197.25 KB 或单域新增 JavaScript 超过 100 KB 视为失败。

测试环境发布必须使用不可变目录；切换前核对服务器当前版本，切换后验证固定路由 HTTP 200、gzip/缓存头、API/Worker 健康和核心写操作幂等。上一不可变目录保留为回滚点。
