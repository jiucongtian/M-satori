# 研发数据中心本轮验证（2026-09-06）

关联 Issue：#127。

## 统计契约

- 从 GitHub 拉取完整 release/r1.0、release/r1.1 历史，固定每份快照的 SHA。
- Release 提交数：R1.1 相对两分支共同祖先；R1.0 从仓库起点。组件按路径分别计算，一次跨组件提交可同时出现在多个组件，不能相加作仓库唯一提交数。
- 历史累计提交数：该 SHA 可达的目录提交总数，不采用 REST 首 100 条小计。
- 代码总行数：指定 SHA 的受支持源码文件物理行数，含注释、空行和测试；排除生成文件、声明文件、依赖、构建结果和锁文件。不是累计新增行数，也不是可执行语句数。
- R1.0 无运营目录，两个运营组件为 0。
- Git 采集失败不覆盖最近成功快照；缓存使用专用 Docker 卷，无业务数据库迁移。
