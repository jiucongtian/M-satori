## 关键跨模块规则

1. **支付、权益和订单以服务端状态为准**：前端不得把“点击支付”当作“已到账”；支付回调、权益发放和订单状态必须可查询、可幂等。
2. **退款先冻结再处理**：申请退款后，未使用权益立即冻结；审核结果决定实际退款和权益回收。
3. **失败不让用户重复付费**：支付处理中、权益发放中、报告生成中、网络中断均保留原订单/任务，并提供继续入口。
4. **分享默认保护隐私**：出生资料、完整报告和原始问题默认不进入分享内容，用户可主动选择更高展示范围。
5. **范围变更先改矩阵**：原型新增、删除或更改 R1.1 页面时，先更新本矩阵及关联编号，再实现代码。
