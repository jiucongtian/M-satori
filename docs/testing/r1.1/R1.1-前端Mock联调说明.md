# R1.1 前端 Mock 联调说明

状态：开发中
前端原型基线：`M-satoriSrs/h5原型@04d3d8c`

## 当前方式

- 开发命令 `npm run dev` 默认启用 `NEXT_PUBLIC_PROTOTYPE_MODE=true`。
- 页面只能通过 `src/api/client.ts` 读取或写入业务数据；页面组件不得直接请求接口。
- Mock 数据集中在 `src/shared/prototypeData.ts`，Mock 行为由 `src/api/client.ts` 统一分流。
- 已覆盖：会话恢复、档案与四卡初识、18 颗新手礼、每日指引、其他人物档案的创建/编辑/删除。

## 切换真实后端

后端联调时只需将 `NEXT_PUBLIC_PROTOTYPE_MODE=false`，并逐项以 OpenAPI 契约替换 `api/client.ts` 内对应 Mock 分支；页面路由、状态机和组件不应改动。

## 验证边界

- 日常改动：执行受影响模块的自动化用例与构建。
- 打 Tag 或明确要求全量回归：执行 `node tests/r1.1/run-full-regression.mjs`，并同时执行后端 R1.1 契约测试。
