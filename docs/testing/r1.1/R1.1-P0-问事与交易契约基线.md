# R1.1 · P0 问事与交易契约基线

## 定位

当前 `release/r1.1` 尚未包含后端源码，因此本文件及相邻的 OpenAPI/Mock 测试是**方案 C：契约先行**。它们用于约束接口实现，不能计入真实后端集成测试覆盖率。

## 正式文件

- 接口契约：`backend/openapi/r1.1-p0-contract.json`
- Mock 场景：`backend/tests/contract/fixtures/r1.1-p0-scenarios.json`
- 可执行契约检查：`backend/tests/contract/r1.1-p0-contract.test.mjs`

## 已覆盖的 P0 规则

1. 问事创建、抽牌、生成和重试均拥有稳定任务标识与幂等键。
2. 抽牌后卡牌与位置冻结；重试不得重新抽牌或重复扣费。
3. 报告失败、离开页面、弱网恢复均保留原任务与卡牌。
4. 创建订单与支付回调均幂等；付款成功但权益未到账时必须可恢复，禁止重复购买。
5. 退款申请立即冻结未使用权益，订单、退款和流水状态一致。

## 后端代码进入 R1.1 后的迁移规则

- 将契约合并进正式 `backend/openapi/openapi.yaml`。
- 将 Mock 场景改为真实 API 集成测试，接入测试数据库与支付回调模拟器。
- 只有完成以上两项后，`R11-CORE-*`、`R11-PAY-*`、`R11-REFUND-*` 才可标记为“真实后端测试通过”。
