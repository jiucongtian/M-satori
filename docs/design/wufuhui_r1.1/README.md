## 基线与设计原则

根据用户确认，沿用以下两套原型的视觉与信息架构，按 R1.1 用户故事做增量设计，不采用此前另起风格的生成草图。

- [H5 原型](https://github.com/jiucongtian/M-satoriSrs/tree/main/h5%E5%8E%9F%E5%9E%8B)：复用基础 CSS、字体/色彩令牌、生命轨道、首页深绿能量卡及报告分区结构。
- [运营平台原型](https://github.com/jiucongtian/M-satoriSrs/tree/main/operations%20portotyp)：保留深绿色侧栏、顶部筛选带、浅绿信息带和横向页签。该路径现有交付为研发数据中心的图片原型，不是可直接运行的完整运营前端；以它提供的公共框架为参考，新配置归入“系统配置”。
- 本次参考提交：`b0cf6e010cf28979c7b0f8267bbd3173fda1553f`。
- 用户故事：GitHub #133—#148，对应 US-01—US-16；原型页面内可打开关联故事。

## 运行与入口

源码在 [prototype](../../../prototype/README.md)，本地预览 http://127.0.0.1:3111/ 。顶部切换运营管理平台、H5 用户原型、设计对照与故事。手机上通过“演示设置 / 页面导航”展开场景控制。

独立预览目录用于隔离演示数据与正式服务，视觉仍继承上述参考基线；不替换现有正式前后台。此次不部署生产环境，也未发布到旧 Sites 项目。

## 边界与待补充

正式 Logo、小岁画像、人称、五福报告模板仍待确认。当前画像为明确占位，卡牌为固定示例，不执行真实排盘、随机抽卡或报告计算；首页不标记真实能量等级。示例时间固定为 2026-09-11。

首次权益来源、额度、多卡组合、失败先去首页等仍为 PRD 中的待决策项；页面编号默认关闭、单卡强制开启且三种模式默认全开、保存后立即生效已冻结。当前以演示路径表达，不表示已经形成产品最终决策。账号与流程仅保存在当前浏览器，模拟恢复不等于真实多端恢复；跨日、真实账务、权限和任务接口需要后续实现验收。分享支持结构预览和复制演示入口，不接通实际海报生成/保存服务。

页面编号优先沿用 H5，新增页使用临时编号，设计冻结时统一登记。R1.2 的关系匹配、卡牌皮肤、真太阳时，以及语音不纳入本次。
