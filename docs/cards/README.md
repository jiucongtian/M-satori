# 生命智慧卡牌资产

本目录保存身心游默认卡牌主题 `satori-default-v1` 的已确认卡面与映射清单。

## 生肖母版一致性规则

- 六十甲子使用十二个固定生肖母版。
- 每个生肖在整套牌中只允许一个确定的线稿形象。
- 同一生肖对应的五张卡牌必须复用完全相同的生肖线稿，包括姿态、朝向、比例、轮廓和细节。
- 同生肖卡牌之间只替换序号、干支、四季、天赋印记、才能印记和路途印记。
- 禁止为同一生肖逐张重新生成形象。
