# Satori R1.0 前端研发基线

状态：已冻结  
版本：R1.0  
负责人：Frontend

## 一、R1.0 九项功能

1. 手机号登录与注册。
2. 创建本人生命智慧档案。
3. 四张关系卡牌结果。
4. 新用户智慧种子赠送。
5. 今日首页。
6. 每日指引生成与查看。
7. “我的”基本页面。
8. 生命智慧档案库基础能力。
9. 智慧种子体验额度账户及使用记录。

## 二、研发口径

- 产品界面统一使用“生命智慧档案”“生命之光”“每日指引”。
- 后端 `life-profile`、`life-report`、`daily-insight` 保持接口命名，不直接暴露给用户。
- 四柱结果固定映射为：年→时空关系、月→事业关系、日→家庭关系、时→自我关系；界面不提示年月日时。
- 后端已定义的接口直接接入；未定义能力使用候选契约与 Mock，并标记 `CONTRACT_PROPOSED`。
- R1.0 正式发布前，所有阻塞上线的 Mock 必须切换为真实接口。
- 页面统一展示 `R1.0 · PAGE-CODE` 标签；路由元数据同时记录 Release 和页面编号。
- 智慧种子仅表示平台免费赠送、会员附赠或学院配置的 AI 体验额度，不可购买、充值、提现、转赠或交易；R1.0 不开放商城、实体商品兑换和人工服务支付。
- AI 生成的每日指引与生命智慧初识必须展示统一 AI 标识和非医疗、非投资、非法律、非未来保证边界。
- 字体、字号与授权管理统一遵循《R1.0-字体与排版规范》；业务源码不得直接指定未经批准的系统或商业字体。

## 三、上线门槛

- H5 原型还原度必须达到 100%；正式前端不得自行改变已确认页面的结构、文案、视觉、动效和交互路径。
- 每个 R1.0 页面必须在统一手机视口下完成原型基准截图与研发页面的视觉回归对比；存在可见差异不得标记为 `accepted`。
- 响应式适配只解决不同设备的安全区域与可用性，不改变基准视口中的原型设计。
- 九项功能主路径与异常路径完成。
- 必需后端接口全部真实可用并通过契约测试。
- 单元与集成测试通过，核心业务模块覆盖率不低于 80%。
- E2E 覆盖注册、建档、赠种、每日指引和回访首页五条关键路径。
- 无 P0/P1 未关闭问题；P2/P3 必须进入已知问题清单。
- 测试环境验收通过，构建可复现，具备回滚版本。
- 字体依赖、授权原文和合规自动化检查完整，正式构建不得依赖第三方字体 CDN 或用户设备字体。
